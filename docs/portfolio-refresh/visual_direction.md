# Visual direction

Keep the existing visual system:

- Background: `#111218` / `#0d0e13`.
- Text: `#e4e1ea`; supporting text: `#cfc6ae`.
- Accent: gold `#f4d03f`, cyan `#8fcdfa`, peach `#fec7a5`.
- Borders: 4px pixel-like strokes; shadows use hard offsets rather than blur-heavy elevation.
- Type: retain the existing display font and uppercase micro-labels; use sentence case in descriptions for readability.

Use the existing gold and featured card variants to create rhythm. Avoid product screenshots that could imply a public deployment; the existing abstract network texture remains decorative and is given accurate alt text.
