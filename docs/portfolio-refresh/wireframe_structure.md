# Portfolio refresh wireframe

- Desktop portfolio: `[hero copy]` then `[status strip]`, followed by a responsive card grid. Each card is `[icon + id] [name] [summary] [tags] [purpose] [repo action]`.
- Mobile portfolio: retain the hero and status strip; cards become one column and actions remain full-width/tappable.
- Project detail desktop: `[feature case study] [repository side card]`, then two companion cards and a portfolio-summary band.
- Home: retain the asymmetric four-card selected-work layout; use the large card for RustFlow and the two small cards for Agent Security Evals and EvoLife.

Interactions are limited to navigation and outbound repository links. A local-only project is visibly labelled rather than given a non-working link.
