# Component inventory

- `PortfolioCard`: project id, icon, title, summary, tags, purpose, optional repository URL.
  - Public state: `Open Repo` and icon link.
  - Local-only state: non-interactive `Local prototype` label.
- `ProjectMainCard`: featured project architecture summary, stack tags, repository action.
- `ProjectMiniCard`: supporting project name, short scope, stack, and focus.
- `HomeProjectCard`: selected-work summary sized for the existing asymmetric grid.
- `AppLink`: existing internal/external link component; all outbound links use `target="_blank"` and `rel="noreferrer"`.
