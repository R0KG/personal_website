# Responsive and interaction rules

- Breakpoints remain the existing layout breakpoints: desktop above 1100px, compact tablet below 1100px, mobile below 760px.
- At 1100px, project grids collapse to one column and the large home card loses its row span.
- At 760px, preserve readable card descriptions and keep the existing button minimum height for touch targets.
- Hover and keyboard focus use the existing small upward translation and visible focus treatment.
- Respect the existing reduced-motion behavior for Framer Motion transitions; no new continuous animation is introduced.
